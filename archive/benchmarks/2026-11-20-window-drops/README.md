# nRF window_drops in tracking, 2026-11-20

> Raw per-leg logs and JSON stay on the bench machine and are regenerated by the committed script (see `docs/preservation.md`). The committed numbers are in this README, `legs.tsv`, `image-configs.txt`, the `*-summary.json` files and the `*-diag-summary.txt` 0xF7 diffs.

Backend drift item 5 (59ae9db + a23674a) added a per-frame receive window-edge
check to the nRF backend: in `radio_isr`'s END branch a frame whose `t_sync`
falls outside `[t_open, t_close]` is dropped and counted in `window_drops`
(0xF7 page 4, `RADIANT_RADIO_DIAG_WINDOW_DROPS`). TODO.md left one bench check
open: confirm `window_drops` stays 0 in normal tracking on real hardware. A
non-zero count would mean the check drops good frames.

## Result

**PASS on both images.** `window_drops` = 0 over 900 s of tracking on each, and
DUT loss matched or beat the Garmin in the same window. All misses had an
RX_FAIL on both receivers.

| leg | image | session | window_drops | DUT loss (exact) | DUT RX_FAIL | Garmin loss (exact) | Garmin RX_FAIL | reboots / asserts |
|---|---|---|---|---|---|---|---|---|
| `wd_mpsl` | MPSL gate, sha256 `117028d4...126701a` | 900 s (clean at 928.0 s) | **0** | 0.33 % (12/3603, -41.6 dBm) | 12 | 0.42 % (15/3605) | 15 | 0 / 0 |
| `wd_dir` | direct, sha256 `9cc91677...cfe1c844e` | 900 s (clean at 927.5 s) | **0** | 0.36 % (13/3604, -41.9 dBm) | 13 | 0.64 % (23/3605) | 23 | 0 / 0 |

Other 0xF7 deltas over the session (before = after boot with the master on air
but the DUT channel not yet open; after = once `ant_verify` closed):

| counter | wd_mpsl | wd_dir |
|---|---|---|
| rx_posted / sync_entries | 3608 / 3602 | 3607 / 3598 |
| term_ok / term_empty / term_error | 5 / 11 / 0 | 1 / 13 / 1 |
| sw_addr_mismatch | 0 | 0 |

`slots_missed` equals the RX_FAIL count on each leg (12 and 13), so every miss
was an empty receive window, not a frame thrown away after sync.
